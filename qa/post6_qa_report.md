### FAIL·CONDITIONAL 항목 상세

#### ❌ 수치 출처 URL 본문 미삽입

- **항목명**: 9,826보·50%·주360분 출처 URL 본문 병기
- **현재 상태**: H2-② 단락에 "국제 메타분석 연구에 따르면", "연구 결과가 보고됐습니다" 문구만 있고 클릭 가능한 앵커링크 없음.
- **offpage 확정 URL**:
  - 9,826보·50%: `https://pubmed.ncbi.nlm.nih.gov/36066874/` (JAMA Neurology 2022)
  - 주360분·아밀로이드 베타: `https://www.sciencedirect.com/science/article/pii/S2274580725001475`
  - 일반 운동 근거: `https://www.dementia.or.kr/general/bbs/index.php?code=story&page=1&number=1059&mode=view`
- **수정 권고**: writer가 H2-② 내 해당 수치 문장에 3개 외부링크를 `rel="nofollow noopener"` 앵커태그로 삽입. 앵커텍스트는 offpage 보고서 제안안 사용.

#### ⚠️ "치매 예방" 단정 표현 4건 잔존

- **항목명**: "치매 예방" → "치매 위험 감소(에 도움)" 표현 전수 교체
- **수정 대상 4건**:
  1. H2-② 제목: `하루 몇 보가 치매 예방에 충분할까` → `하루 몇 보가 치매 위험을 낮출까` (또는 유사 표현)
  2. 본문: `치매 예방 운동의 핵심은 강도가 아니라 지속성입니다` → `치매 위험 감소 운동의 핵심은 강도가 아니라 지속성입니다` (또는 "뇌건강 걷기의 핵심")
  3. 마무리: `걷기 운동 치매 예방의 핵심은 단 하나입니다` → FK 직접 언급이므로 부분 허용 가능하나, 바로 뒤 문장과 함께 맥락 재확인 권고
  4. 내부링크 앵커: `치매 예방에 좋은 음식` → 해당 post (#post-194)의 실제 제목·키워드와 정합성 유지하면서 "뇌건강에 좋은 음식" 또는 "치매 위험을 낮추는 음식" 검토

  > **단, FK 허용 범위**: "걷기 운동 치매 예방"은 포커스 키워드 자체이므로 H1·FK 직접 언급·카테고리 슬러그는 수정 제외. 브리프 지시는 표현(효과 주장) 단정을 막는 것이 목적.

#### ⚠️ H2-① 과학 근거 섹션 논문/학회 직접 인용 부재

- **항목명**: EEAT H2-① 직접 인용
- **현재 상태**: BDNF·해마 부피 등 근거 내용은 있으나 출처 없음.
- **수정 권고**: H2-① 단락 말미 또는 해당 주장 직후에 대한치매학회 URL 또는 JAMA Neurology 인용을 `(대한치매학회, 2024)` 형태 또는 앵커링크로 추가. 외부링크 삽입과 연계해 처리 가능.

### 종합 의견 (qa 에이전트)

Post #6 초안은 구조·분량·광고 마커·면책·위젯 면책 문구 측면에서 기준을 충족한다. CONDITIONAL 판정 근거는 두 가지다.

**첫째**, offpage 에이전트가 확정한 외부링크 3개가 본문에 삽입되지 않아 수치 출처 병기 요건을 미충족. 이는 writer가 offpage 보고서 수령 후 앵커링크를 본문에 삽입하는 후처리 단계가 누락된 것으로 보인다.

**둘째**, "치매 예방" 단정 표현이 H2 제목·본문·내부링크 앵커에 복수 잔존한다. 브리프 지시("치매 예방" → "치매 위험 감소")를 FK 자체를 제외한 범위에 전수 적용하지 않은 상태다.

두 항목 모두 writer 단계에서 수정 가능한 수준이다. 외부링크 삽입 + 표현 교체 완료 후 재검수하면 PASS 진입 가능하다. 위젯 품질, 광고 마커, 면책, 분량, 메타 헤더는 모두 기준 충족 상태다.
