## 2. 인지 도메인 활성화 수준

| 인지 도메인 | 활성화 수준 | 근거 |
|---|---|---|
| **억제 제어 (Inhibitory Control)** | 🔴 High | 글자 의미(읽기 자동화) 억제 후 잉크 색상 응답 필요 |
| **주의력 (Attention)** | 🔴 High | 불일치 자극(≥60%) 속에서 정확한 색상에 집중 유지 |
| **처리 속도 (Processing Speed)** | 🟡 Mid-High | 60초 안에 15문제 반응 시간 측정 |
| **실행 기능 (Executive Function)** | 🟡 Mid | 색상 정보와 언어 정보 간 갈등 해소·전략 전환 |
| **작업 기억 (Working Memory)** | 🟢 Low | 규칙(색상 응답) 기억 유지 — 부하 낮음 |

**스트룹 효과 원리 (포스트 본문 설명용)**:
- 사람 뇌는 글자를 '읽는' 자동 반응이 색상 인식보다 빠름
- 글자 의미와 잉크 색이 불일치할 때 반응 시간 증가 = 억제 제어 부담
- 이 갈등을 반복 해소하면 전두엽(실행 기능 담당) 활성화 훈련 효과

## 3. 게임 규칙

### 규칙 요약 (1~2문장)
- **사용자가 할 일**: 화면에 나타나는 색상 단어(예: "빨강")의 **글자 색깔**을 보고, 해당 색상 버튼(또는 키보드 숫자)을 누른다. 단어의 뜻이 아닌 **잉크 색상**에만 집중해야 한다.
- **성공 조건**: 15문제 중 최대한 많이 정확하게, 최대한 빠르게 응답. 60초 타이머 안에 완료.

### 상세 진행 흐름

```
[화면 1] 랜딩 — 게임명 + 간단 설명 + [시작하기] 버튼
    ↓
[화면 2] 난이도 선택 — 쉬움 / 보통 / 어려움
    ↓
[화면 3] 게임 방법 안내 (3초 카운트다운)
    - "글자의 색깔을 보고 버튼을 누르세요"
    - 예시 1문제 (연습 없이 설명만)
    ↓
[화면 4] 게임 진행
    - 상단: 남은 시간(초) + 현재 문제 번호(N/15)
    - 중앙: 자극 단어 (크게, 잉크 색상 적용)
    - 하단: 색상 버튼 4개 (빨강 / 파랑 / 초록 / 노랑)
    - 키보드: 1=빨강 2=파랑 3=초록 4=노랑
    ↓
[화면 5] 결과 화면
    - 정답 수 / 15문제
    - 평균 반응 시간 (ms → "X.X초")
    - 4단계 등급 + 등급 설명
    - 인지 건강 정보 1줄
    - [다시 도전] [다른 난이도 도전] 버튼
    - 연계 내부링크 2개
```

## 4. 자극 구성

### 색상 정의

| 색상명(한글) | 버튼 라벨 | 잉크 HEX | 키보드 단축키 |
|---|---|---|---|
| 빨강 | 빨강 | #E53935 | 1 |
| 파랑 | 파랑 | #1E88E5 | 2 |
| 초록 | 초록 | #43A047 | 3 |
| 노랑 | 노랑 | #F9A825 | 4 |

### 자극 조건

| 조건 | 정의 | 비율 |
|---|---|---|
| **불일치 (Incongruent)** | 단어 의미 ≠ 잉크 색상 (예: "빨강" → 파란 잉크) | ≥ 60% (9~10문제) |
| **일치 (Congruent)** | 단어 의미 = 잉크 색상 (예: "파랑" → 파란 잉크) | ≤ 40% (5~6문제) |

**불일치 60% 이상 이유**: 스트룹 간섭 효과를 충분히 측정하려면 불일치 문제가 다수여야 함. 일치 문제는 워밍업·리듬 유지 목적.

### 난이도별 자극 차별화

| 난이도 | 자극 변경 내용 | 불일치 비율 | 타이머 |
|---|---|---|---|
| **쉬움** | 글자 크기 크게 (48px) + 버튼 크게 | 60% | 90초 |
| **보통** | 글자 크기 보통 (40px) | 67% (10/15) | 60초 |
| **어려움** | 글자 크기 작게 (32px) + 색상 텍스트 색조 미세 변형 추가 | 73% (11/15) | 45초 |

> **시니어 배려**: 쉬움 모드는 90초 타이머 + 큰 버튼 (최소 56px 높이) — 모터 제어 어려움 고려

## 6. 점수 체계

### 기본 점수 계산

```
총점 = 정답 점수 합산 + 속도 보너스 점수

정답 1개 기본점 = 10점 (최고 150점)

속도 보너스 (정답인 경우에만 적용):
  반응 시간 < 500ms  → +5점 (번개 반응)
  반응 시간 500~800ms → +3점 (빠른 반응)
  반응 시간 800~1200ms → +1점 (보통 반응)
  반응 시간 > 1200ms → +0점 (느린 반응)

최고 점수: 15문제 × (10 + 5) = 225점
```

### 등급 판정 기준

| 등급 | 조건 | 등급 라벨 | 의미 |
|---|---|---|---|
| S (최고) | 정답률 ≥ 87% (13/15+) AND 평균 반응시간 < 700ms | 집중력 탁월 | 억제 제어 매우 우수 |
| A (우수) | 정답률 ≥ 73% (11/15+) AND 평균 반응시간 < 1000ms | 집중력 양호 | 평균 이상 억제 제어 |
| B (보통) | 정답률 ≥ 60% (9/15+) | 집중력 보통 | 지속적 훈련 권장 |
| C (개선 필요) | 정답률 < 60% (8/15 이하) | 집중력 훈련 필요 | 매일 5분 연습 권장 |

> **YMYL 주의**: 등급은 의료 진단이 아님. "이 결과는 참고용이며 의료적 진단이 아닙니다." 문구 필수 표시.
