## 🚨 최상위 정체성 원칙 — 도박 아님, 두뇌 트레이닝 (★ 2026-05-19 영구 각인)

**모든 게임 기획의 출발점이자 절대 기준.**

> 게임 메카닉·점수 체계·난이도 설계 그 어느 것도
> "도박 게임"처럼 보이는 구조를 가져서는 안 된다.

| 구분 | 기획 원칙 |
|---|---|
| ❌ 절대 금지 구조 | 배팅/판돈 시스템 · 금전 득실 구조 · 도박성 랜덤 보상 |
| ✅ 허용 구조 | 인지 성과 기반 점수 · 훈련 달성 배지 · 레벨업 시스템 |
| ✅ 점수/보상의 의미 | 금전이 아닌 **인지 훈련 성과의 시각화** |
| ✅ 재방문 유도 방식 | 도박성 중독(손실 회피) 금지 → 성취감·인지 향상 동기 활용 |

### ❌ 기획서에서 절대 사용 금지
- 배팅, 베팅, 판돈, 칩, 캐시, 잭팟, 보너스 라운드(도박 연상)
- 손실 회피 심리 악용 메카닉 (도박 중독 유발 패턴)

### ✅ 기획서에서 적극 활용
- 인지 성과 측정 (반응시간·정확률·점수)
- 성취 배지 시스템 (뇌건강 달성 동기 강화)
- 난이도 프로그레션 (인지 부하 점진적 증가)

### 💡 게임 설계 철학
이 게임들은 시니어가 즐기면서 자연스럽게 두뇌를 훈련하는 도구다.
오락성과 교육성을 동시에 갖추되, **치료적·재활적 가치**를 전달하는 것이 목표.
**배지**: 게임 기획 · 뇌건강 교육 · 시니어 UX · 메카닉 설계

## 🎯 뇌건강 게임 설계 원칙

### 1. 교육적 가치 우선
모든 게임은 **뇌건강·인지 기능** 관련 학습 효과를 포함해야 한다.

| 게임 유형 | 훈련 인지 기능 | 예시 |
|---|---|---|
| 자가진단 체크리스트 | 자기 인식·주의 | 건망증 5항목 자가점검 |
| 기억력 매칭 | 단기 기억·시각 처리 | 카드 뒤집기 매칭 게임 |
| 단어 연상 | 언어 능력·장기 기억 | 단어-그림 연결 퀴즈 |
| 계산 속도 | 처리 속도·집중력 | 간단 연산 타이머 게임 |
| 순서 기억 | 작업 기억 | 숫자·색상 순서 따라하기 |
| 생활 습관 퀴즈 | 지식·판단력 | 치매 예방 O/X 퀴즈 |

### 2. 시니어(60대+) 친화 설계 필수 원칙

| 원칙 | 내용 |
|---|---|
| **단순성** | 한 화면에 정보 최소화. 규칙은 1문장 설명 가능해야 함 |
| **명확한 피드백** | 정답·오답 즉각 시각 피드백 (색+텍스트 동시) |
| **시간 압박 최소화** | 타이머는 선택 사항. 기본은 무제한 시간 |
| **재도전 허용** | 틀려도 즉시 재시작 가능. 좌절감 최소화 |
| **성취감 설계** | 완료 시 긍정적 결과 메시지 필수 |
| **정보 제공** | 게임 후 관련 뇌건강 정보 1줄 이상 제공 |

### 3. 애드센스 체류 시간 극대화

| 전략 | 구현 방법 |
|---|---|
| 재방문 유도 | "오늘 기록: N점. 내일 다시 도전!" 메시지 |
| 포스트 연계 | 결과 화면에서 관련 포스트 2개 내부링크 |
| 공유 유도 | 결과 공유 버튼 (SNS 바이럴) |
| 레벨 구조 | 쉬움/보통/어려움 3단계 난이도 |

## 📋 게임 기획서 표준 양식

game_planner 에이전트는 아래 양식으로 기획서를 작성해 lead에 제출.
lead 승인 후 → writer(텍스트) → design(UI) → game(구현) 순서로 진행.

```
═════════════════════════
🧩 게임 기획서 — Post #{N}
═════════════════════════
[게임명]: (예: "60초 건망증 자가진단")
[포스트 FK]: (연계 포커스 키워드)
[훈련 인지 기능]: (예: 자기 인식·주의력)
[게임 유형]: 체크리스트 / 퀴즈 / 매칭 / 순서기억 / 기타

[규칙 요약] (1~2문장):
  - 사용자가 할 일: ...
  - 성공 조건: ...

[문항/콘텐츠 구성]:
  - 총 문항 수: N개
  - 문항 유형: O/X / 4지선다 / 체크박스 / 입력
  - 예시 문항 1~3개:
    Q1. ...
    Q2. ...

[점수 체계]:
  - 기본 점수: 정답 1개당 N점
  - 보너스: (해당 시)
  - 최고점: N점

[난이도]:
  - 쉬움: (기준)
  - 보통: (기준)
  - 어려움: (기준, 선택)

[피드백 메시지 구조] (writer 작성 후 기재):
  - 낮음 (0~N점): ...
  - 중간 (N+1~M점): ...
  - 높음 (M+1~최고점): ...
  - 면책 문구: "이 결과는 의료 진단이 아닙니다."

[UI 요구사항] (design 전달):
  - 레이아웃: 세로 스크롤 / 단일 화면
  - 핵심 컬러: 브랜드 청록 계열
  - 특이사항: ...

[재방문 유도 요소]:
  - 공유 문구: "나는 {N}개 해당! 당신은?"
  - 연계 내부링크: Post #{X} + Post #{Y}

[예상 체류 시간]: N분
[발행 연계 포스트]: Post #{N}
═════════════════════════
```

## 🎮 민화투 2인전 게임 진행 완전 정리

### 초기 설정
- 48장 셔플
- 바닥패 8장 앞면으로 배치
- 플레이어·AI 각 7장 손패
- 나머지 19장 = 더미 (뒤집어 쌓기)
- 선 결정: 낮은 월 패 뽑은 쪽이 선

### 1턴 진행 순서 (플레이어 기준)
1. **손패 내기**: 손패 1장 선택 → 바닥에 같은 월 패 있으면 2장 모두 가져옴
   - 없으면: 바닥에 그냥 내려놓음
2. **더미 뒤집기**: 더미 맨 위 1장 뒤집기 → 바닥에 같은 월 있으면 2장 가져옴
   - 없으면: 바닥에 추가
3. **특수 상황 — 3장 쌓임**: 바닥에 같은 월이 이미 2장 있을 때 내가 1장 내면 3장 모두 가져옴
4. **턴 종료**: AI 차례로 전환

### 종료 조건
- 더미 소진 → 손패 남은 패 모두 바닥에 내고 짝 맞추기 → 점수 계산
- 또는 손패 소진 시 종료

### 점수 계산 (민화투 표준)
```
총점 = 광점수 + 열끗점수 + 띠점수 + 족보점수
광:  모은 광 장수 × 20점
열끗: 모은 열끗 장수 × 10점
띠:  모은 띠 장수 × 5점
족보: 해당 시 각 +3점 또는 +5점
```

**본점수 기준 (2인전)**:
- 전체 패 점수 합산 = 240점
- 본점수 = 120점 (절반)
- 120점 초과 시 승리 / 미만 시 패배 / 동점 시 '본'(무승부)

# 🌐 Brain Games 허브 — 게임 기획 표준 (★ v1.8 신설 — 2026-05-20)

## 허브 페이지 구조 이해

Brain Games 허브(`/brain-games/`)는 게임 선택 로비. 카드 그리드에서 게임을 선택하면 iframe 전체화면으로 전환된다.

```
허브 카드 그리드 → [카드 탭] → 슬라이드업 전환 → iframe 게임 전체화면
```

## 게임 카드 메타데이터 4개 표준 (필수)

신규 게임 기획서에 반드시 아래 4개 항목 포함:

| 필드 | 예시 | 용도 |
|---|---|---|
| `data-title` | "민화투 두뇌훈련" | 전체화면 헤더 표시 |
| `data-badge` | "🧠 기억력" | 카드 배지 |
| `data-src` | "/brain-games/minwhatoo/" | iframe URL |
| `data-thumb` | p{N}c01_og.png URL | 카드 썸네일 |

## 허브 최적 게임 UX 기준

| 원칙 | 내용 |
|---|---|
| 탭 2회 이내 게임 시작 | 카드 탭 1회 → 게임 시작 버튼 1회 |
| 결과 화면 후 순환 흐름 | "다시하기" + "다른 게임" 버튼 필수 |
| "다른 게임" 버튼 동작 | iframe 닫기 → 허브 그리드 복귀 |
| 로딩 스피너 없애기 | 위젯 초기화는 iframe 로드 즉시 |

## 배지 시스템 표준

| 배지 | 표시 조건 | 색상 |

| 🆕 신규 | 등록 후 30일 이내 | 초록 |
