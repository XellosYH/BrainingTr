[공통 — 협업 4원칙 (Claude 행동 가이드)]
신중함 > 속도. 사소한 작업은 판단으로.

1. 행동 전 사고
- 가정은 명시. 불확실하면 질문.
- 다중 해석 가능 시 모두 제시 후 결정 요청 (혼자 결정 X)
- 더 단순한 대안 있으면 제안. 필요 시 푸시백
- 모호하면 멈추고 무엇이 모호한지 명시 후 질문

2. 단순함 우선
- 요청한 것 외 기능 추가 금지
- 일회성 작업에 추상화 금지
- 요청 안 한 "유연성·확장성" 금지
- 일어날 수 없는 시나리오 에러 처리 금지
- "시니어 엔지니어가 과도하다고 할까?" 자문 → Yes면 단순화

3. 외과적 변경
- 요청 외 영역 건드리지 않기 (코드·디자인·문구·포맷)
- 망가지지 않은 것 리팩터링 금지
- 본인이 다르게 했을 스타일이라도 기존 스타일 유지
- 무관한 데드코드 발견 시 보고만 하고 삭제 X
- 본인 변경으로 생긴 고아 항목만 정리
- 모든 변경 라인은 요청에 추적 가능해야 함

4. 목표 주도 실행
- 검증 가능한 성공 기준 정의 후 시작
- "동작하게 해" 같은 약한 기준 → 강한 기준으로 변환 요청
- 다단계 작업: 각 단계마다 검증 항목 명시
- 강한 기준은 자율 루프 가능, 약한 기준은 매번 확인 필요

## 카테고리 SSOT (현행 — 신규 생성은 팀장 승인 필수)

| 카테고리 | slug | 용도 |
|---|---|---|
| 뇌건강 | brain-health | 뇌 활성화·인지 기능·생활 습관 |
| 치매예방 | dementia-prevention | 건망증·치매 초기증상·자가진단·예방 |

- 신규 카테고리 생성 = **팀장 승인 필수** (WP 기본·양산형 카테고리 난립 회피 — dev.md §정합)
- slug 영문만 (한글 슬러그 금지 — dev.md §콘텐츠 단계별 슬러그 정합)

## 카테고리 선정 룰

- 글당 **1차 1개 필수** + 2차 0~1개 선택
- 1차 = 글 핵심 검색 의도·주제 정합 우위 카테고리
- 형제(클러스터) 글은 1차 카테고리 **분산 권장** — 카테고리 페이지 콘텐츠 균형 (예: 형제 글 A=뇌건강 / B=치매예방)
- 2차는 본문 일부 섹션이 다른 카테고리 주제와 겹칠 때만 부착

## 태그 선정 룰

- 글당 **4~5개** (과다 태그 금지)
- slug 영문만 (한글 슬러그 금지)
- FK·핵심 LSI 기반 명사 — 재사용성 높은 일반 명사 우선
- **수치·단발 태그 금지** ("14문항"·"7가지" 류 — 재사용성 0)
- **클러스터 연결용 공유 태그 1개+ 포함 권장** — 형제 글과 공유하는 태그(예: "시니어")로 태그 아카이브 페이지가 클러스터를 묶음
- 신규 태그 생성은 자유(카테고리와 달리 난립 위험 낮음), 단 중복·유사어 회피
