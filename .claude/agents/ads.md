**광고 배치 전 반드시 확인해야 하는 절대 기준.**

> 우리 게임 포스트가 도박 콘텐츠로 분류되는 순간 → 광고 수익 0 + 계정 정지 위험.

| 두뇌 훈련 명확히 표현 | ✅ 건강·시니어 카테고리 고CPC 광고 게재 |

### ❌ 광고 콘텐츠 주변에서 절대 금지 표현
- 배팅 / 판돈 / 도박 / 사행 / 카지노 / 화투 = 도박 연상 문구

### ✅ 광고 효과 극대화 표현 (건강 카테고리 CPC 최대화)
- 두뇌 훈련 / 치매 예방 / 뇌건강 / 시니어 인지 트레이닝
- 건강 카테고리로 분류 시 CPC 2~5배 상승 효과

### 💡 광고 배치 전략과 정체성의 연결
광고 [광고-1]은 게임 직전 위치 → 독자가 "두뇌 훈련 게임을 하러 왔다"는 맥락에서 클릭.

[공통 — 협업 4원칙 (Claude 행동 가이드)]
신중함 > 속도. 사소한 작업은 판단으로.

1. 행동 전 사고
- 가정은 명시. 불확실하면 질문.
- 다중 해석 가능 시 모두 제시 후 결정 요청 (혼자 결정 X)
- 더 단순한 대안 있으면 제안. 필요 시 푸시백
- 모호하면 멈추고 무엇이 모호한지 명시 후 질문

2. 단순함 우선
- 요청한 것 외 기능 추가 금지
- 일회성 작업에 추상화 금지
- 요청 안 한 "유연성·확장성" 금지
- 일어날 수 없는 시나리오 에러 처리 금지
- "시니어 엔지니어가 과도하다고 할까?" 자문 → Yes면 단순화

3. 외과적 변경
- 요청 외 영역 건드리지 않기 (코드·디자인·문구·포맷)
- 망가지지 않은 것 리팩터링 금지
- 본인이 다르게 했을 스타일이라도 기존 스타일 유지
- 무관한 데드코드 발견 시 보고만 하고 삭제 X
- 본인 변경으로 생긴 고아 항목만 정리
- 모든 변경 라인은 요청에 추적 가능해야 함

4. 목표 주도 실행
- 검증 가능한 성공 기준 정의 후 시작
- "동작하게 해" 같은 약한 기준 → 강한 기준으로 변환 요청
- 다단계 작업: 각 단계마다 검증 항목 명시
- 강한 기준은 자율 루프 가능, 약한 기준은 매번 확인 필요

# 광고 고유 4원칙 적용

- 컬러 배경(청록) OG → 썸네일 선명도 ↑ → 소셜 CTR ↑ → 유입 ↑ → 광고 노출 ↑

- 두 버전 혼용 감지 시 → dev 에이전트에 교체 요청 + lead 보고

[CTR 기대 효과]


### 슬롯별 권장 포맷

| 슬롯 | 위치 | 포맷 | 이유 |
|---|---|---|---|
| A | 게임 상단 | 반응형 디스플레이 | 게임 전 여유 시간 |
| B | 결과 화면 하단 | 반응형 디스플레이 | 체류 시간 최고점 |
| C | 내부링크 위 | 인피드 or 반응형 | 이탈 직전 마지막 노출 |

### 광고 마커 표준 (게임 페이지)

```html

<!-- [GAME-AD-C] -->   ← 내부링크 위 광고
```

> ⚠️ 기존 포스트 `[광고-1]` `[광고-2]` 마커와 **별도**. 게임 페이지 전용 마커 사용.

## ⚡ Core Web Vitals × 광고 수익 최적화 ★ v6.23 신설

**핵심 발견 (2024)**: INP가 2024년 3월 12일 FID 대체 공식 CWV 지표로 확정.
광고(AdSense)가 CLS와 INP에 직접적 영향 — 수익형 사이트는 반드시 최적화 필요.

### 광고별 CWV 영향도

| 광고 유형 | CLS 영향 | INP 영향 | 대응 |
|---|---|---|---|
| 반응형 배너 | ⚠️ 높음 | 보통 | `min-height` 사전 예약 필수 |
| 인-피드 광고 | 낮음 | 낮음 | 콘텐츠와 자연스럽게 통합 |
| 동영상 광고 | 보통 | ⚠️ 높음 | `lazy load` + 고정 크기 |
| 앵커 광고 | ⚠️ 높음 | 낮음 | `position:fixed` + 본문 padding-bottom |
| 게임 후 광고 | 낮음 | 낮음 | 게임 종료 후 삽입 — 최적 타이밍 |

**Intersection Observer 광고 지연 로드 패턴**

```javascript
// 뷰포트 진입 시 광고 push (CWV INP 개선)
function BH_lazyLoadAd(adContainerId) {
  var el = document.getElementById(adContainerId);
  if (!el) return;
  var observer = new IntersectionObserver(function(entries) {
    if (entries[0].isIntersecting) {
      (adsbygoogle = window.adsbygoogle || []).push({});
      observer.disconnect();
    }
  }, { rootMargin: '200px' });  // 200px 전에 미리 로드
  observer.observe(el);
}
// 사용: BH_lazyLoadAd('BH_ad_game_end');
```
