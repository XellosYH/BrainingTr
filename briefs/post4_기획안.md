## 1. 키워드 분석

### 포커스 키워드 (FK)
**`건망증 원인 증상`** (3어절)

**선택 이유**:
1. 구글 트렌드 "건망증 이란" +2,900% 급상승 → 정의형 수요 포착, FK는 롱테일화
2. Post #2 "건망증 치매 초기증상"과 주제 겹침 없음 — Post #2는 "구별법", Post #4는 "원인·증상 이해"
3. 수면 부족(Post #3) 내부링크 자연 연결: 원인 항목에 "수면 부족" 포함
4. D안 체크리스트 구조 자연: "나의 건망증 자가점검" → 원인 파악 흐름

### 비교 검토 (비채택 안)
| 키워드 | 비채택 사유 |
|---|---|
| `건망증 이란` (2어절) | FK 단순화 룰 2~3어절 하한에 맞지만 너무 광범위; 타이틀·H1에 흡수 |
| `건망증 심해지는 이유` (3어절) | 좋은 각도이나 FK 검색량 추정 낮음; H2 제목으로 활용 |
| `건망증 뜻 원인 증상 치료` (5어절) | 과도한 어절 수; 짬글 범위 초과 |

### LSI 키워드 5개
1. 건망증 뜻 (트렌드 연동 — "건망증 이란" 검색자 흡수)
2. 기억력 저하 원인 (원인 섹션 자연 삽입)

4. 건망증 개선 방법 (행동 의도 — CTA 연결)

- 힌트 줘도 기억 못 함, 같은 말 반복, 가족이 먼저 인지 → Post #2 자가체크 14문항 연결

- ④ 두뇌 트레이닝 — 기억력 게임·퍼즐·새로운 도전
