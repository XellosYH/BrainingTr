## 1. 키워드 분석

### 포커스 키워드 (FK)
**`수면 부족 치매 위험`** (공백 기준 4어절 → 롱테일 정량 정의 ✅)

**롱테일 판정 근거** (writer.md v7.25 §롱테일 정량 정의):
- 공백 기준 4어절 → 정량 기준 충족 ✅
- 명사 키워드 3개+ (수면/부족/치매/위험 4개) → 기준 초과 ✅

**선택 이유**:
1. 60대 시니어의 공통 경험 — "잠이 줄었다"는 불안감 공감 직결
2. "30%↑" 통계 — 수치형 헤드라인 훅 가능
3. 글림프 시스템 — 의학 메커니즘 = EEAT 전문성 + 시니어에게 새 정보
4. Post #1(뇌 활성화 습관), Post #2(건망증 자가진단)와 주제 겹침 없음
5. D안 체크리스트 구조 자연스러움 — "내 수면 습관 점검" 흐름

### 비교 검토 (비채택 안)
| 키워드 | 비채택 사유 |
|---|---|
| 치매 예방 음식 60대 | 대형 의료 미디어(하이닥·코메디닷컴) 지배 → 경쟁 과다 |
| 걷기 운동 치매 예방 효과 | 좋은 각도이나 수면보다 데이터 스토리 약함, Post #4~5 보류 |

### LSI 키워드 5개
1. 글림프 시스템 (과학 메커니즘 — EEAT 전문성)
2. 아밀로이드 베타 (치매 단백질 — 신뢰 출처 연결)
3. 60대 수면 시간 (타깃 연령 + 검색 의도)
4. 숙면 방법 (행동 의도 — CTA 연결)
5. 치매 예방 생활 습관 (Post #1 내부링크 연결 키워드)

## 4. 글 구조 (D안 표준)

### H1 (본문용 — 오인 프레이밍형)
```
"잠이 줄어드는 건 노화인 줄 알았는데" — 수면 부족 치매 위험과 60대 숙면 체크리스트 5가지
```

### SEO Title 후보 3개 (writer 최종 결정용)
1. `수면 부족 치매 위험 30%↑ — 60대 숙면 습관 체크리스트 5가지` (38자)
2. `수면 부족 치매 위험, 얼마나 심각할까 — 60대 수면 자가진단` (33자)
3. `잠이 줄면 치매 위험? 수면 부족 치매 관계와 60대 숙면 체크` (34자)
- **권고 1순위**: 1번 (FK 시작 + 수치형 30%↑ 훅 + "5가지" 수치 → 전략 5 §1 정합)

### 메타 디스크립션 후보 (120~155자)
```
자꾸 잠이 줄어드는 게 단순 노화일까요? 수면 6시간 미만이면 치매 위험이 30% 높아진다는 연구 결과가 있습니다. 뇌 청소 시스템 '글림프'와 숙면 체크리스트 5가지, 지금 바로 확인해보세요.
```
(측정: 약 105자 — writer 초안 단계에서 120자 이상으로 정밀화 필요)

□ 아침에 일어나도 피곤하고 개운하지 않다
□ 낮에 심하게 졸려 일상이 방해된다

- 6시간 미만 수면 → 치매 위험 30%↑ (UCL·프랑스 국립보건의학연구원, 2021)
- [광고-1] ← H2-2 직후 배치 (권위 단락 +1 이후)

H2-3: 60대 적정 수면 시간은 몇 시간일까
- 7~8시간 권고 (대한수면학회·세계수면학회)
- 60대 이후 수면 구조 변화 (서파수면 감소) — 자연 노화 vs 문제 신호 구분

H2-4: 오늘부터 실천하는 숙면 습관 4가지
- 취침·기상 시간 규칙화
- 취침 1시간 전 스마트폰·밝은 조명 제한
- 카페인·알코올 오후 3시 이후 제한
- 낮잠 20분 이내 (오후 3시 이전)

[카드 이미지 삽입 위치 — H2-4 직후]

[광고-2] ← 카드 이미지 직후

H2-5: 수면 문제가 계속된다면 — 언제 전문가 상담이 필요한가
- 수면 장애·수면 무호흡 감별 신호
- 보건복지부 치매상담콜센터 1899-9988 안내
